# Bitcoin Cash (BCH)

| | |
|---|---|
| **Year** | 2017 |
| **Type** | Hard fork (permanent chain split) |
| **Status** | Active (separate chain) |

## What it does

Bitcoin Cash increased the block size limit from 1 MB to 8 MB (later 32 MB), allowing more transactions per block. It forked from Bitcoin at block 478,558 on August 1, 2017.

## Why it happened

The "block size debate" dominated Bitcoin development from 2015-2017. One camp argued that Bitcoin needed larger blocks to scale on-chain. The other argued for keeping blocks small and scaling via layer-2 solutions (Lightning Network).

When SegWit activated (providing a modest capacity increase via the weight system rather than a raw block size increase), the large-block camp forked off to create Bitcoin Cash.

## Key details

- Forked at block 478,558 (August 1, 2017)
- Initial block size: 8 MB (later increased to 32 MB)
- All Bitcoin holders at the fork received equal BCH
- Removed SegWit and Replace-By-Fee (RBF)
- Added Emergency Difficulty Adjustment (EDA) to handle hashrate fluctuations

## Outcome

Permanent chain split. Bitcoin Cash maintains its own chain, development team, and community. Market value is a small fraction of Bitcoin's. The fork demonstrated that hard forks without overwhelming consensus create permanent splits rather than upgrades.
